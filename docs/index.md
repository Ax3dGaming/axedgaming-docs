# AxedGaming Mods Documentation

Welcome to the official documentation for AxedGaming mods.

## Available Mods

### Scavenging

Scavenging is a lightweight, data-driven loot system for Minecraft modpacks.

Players can search blocks using tools or their bare hands and receive configurable loot based on custom recipes.

Features:

* Data pack support
* KubeJS support
* JEI integration
* Multiple loot outputs
* Per-output drop chances
* Optional tool durability usage
* Bare hand recipes

Use the navigation menu to access the Scavenging documentation.
